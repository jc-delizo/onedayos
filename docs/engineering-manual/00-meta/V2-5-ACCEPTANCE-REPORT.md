# V2-5 Acceptance Report

Status: Founder Accepted

Founder acceptance date: 2026-07-24

This acceptance applies to the controlled V2-5 bounded export package. It does not imply public-demo or production approval.

## Dependency

Exact `exceljs@4.4.0` uses only the scoped `exceljs -> uuid@11.1.1` override. CommonJS, dynamic import, UUID call-site, clean-install, workbook round-trip, Next server build, and all audit gates pass. See the compatibility-gate report.

## Export Architecture and Permissions

The reusable server-only adapter generates bounded CSV/XLSX from existing tenant-scoped services. Binary success and standard JSON failure are explicit. Each of the 11 eligible tables requires read plus a separate export permission. Org Admin wildcard is capable; Warehouse Operator remains denied and has no Export control.

## Eligible Tables

Stock Levels, Stock Movements, Stock Adjustments, Products, Product Categories, Customers, Suppliers, Warehouses, Employees, Branches, and Departments are included. Platform Users/auth, tracking settings, dashboards, Process Flow, and security metadata are excluded.

## CSV and XLSX Verification

CSV verifies UTF-8 BOM, CRLF, quotes, comma/newline handling, stable headers, null/number/boolean/Date serialization, and spreadsheet-injection protection. XLSX readback verifies a valid ZIP signature, safe worksheet, stable columns, typed cells, freeze pane, autofilter, width caps, and absence of cell formulas.

## Filtering, Sorting, Selection, and Limits

Export query schemas reuse V2-2 allowlists without pagination. Existing list services provide tenant, soft-delete, filter, and deterministic sort behavior. Selected IDs are deduplicated and safely resolved within current filters. Limits are 10,000 filtered rows and 1,000 selected IDs; failures occur before serialization and never return a partial file.

## Security Review

No internal/tenant/auth IDs, soft-delete fields, permission metadata, tokens, or secrets are columns. Tenant identity is recursively rejected. Filenames and headers are generated by trusted code. ExcelJS is server-only. Binary responses are `no-store` and `nosniff`.

## Accessibility

The export trigger, format/scope actions, exact counts, disabled state, preparing state, and error/success announcements have automated Testing Library and axe regression coverage. This is not a formal WCAG certification.

## Manual Visual and Download Review

The controlled production review passed on port 1320. Org Admin downloaded CSV from every non-empty eligible demo table and XLSX from Stock Levels; Customers and Employees correctly returned the standard `EXPORT_EMPTY` JSON response because the canonical demo contains no rows for those resources. Selected and filtered Stock Levels exports each contained exactly the requested row, and ExcelJS readback confirmed the expected worksheet, headers, typed numeric values, and absence of formulas. The Warehouse Operator received a standard JSON `403 FORBIDDEN` response from the live API and had no Export control in the UI.
