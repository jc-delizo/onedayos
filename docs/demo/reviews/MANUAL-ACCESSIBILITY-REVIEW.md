## Shared Checks

- [ ] Keyboard-only navigation reaches login, apps launcher, sidebar, app switcher, profile menu, and primary actions.
- [ ] Focus indicators are visible in Light mode.
- [ ] Focus indicators are visible in Dark mode.
- [ ] App switcher and profile menu have accessible names.
- [ ] Appearance choices expose visible and non-color-only selected state.
- [ ] Page headings and breadcrumbs identify the current page.
- [ ] Loading states communicate the page context.
- [ ] Error states are clear and do not expose technical stack details.

## Inventory Checks

- [ ] Process Flow is understandable without relying only on color or arrow direction.
- [ ] Stock Levels table headers make sense when read out of context.
- [ ] Low-stock status includes text, not color alone.
- [ ] Stock Adjustment form fields have labels.
- [ ] Validation errors are associated or clearly placed.
- [ ] The submit button pending/disabled state is understandable.

## Organization Checks

- [ ] People page distinguishes organization people from login users.
- [ ] Branches & Departments is understandable as company structure.
- [ ] Settings does not expose unavailable controls as active.
